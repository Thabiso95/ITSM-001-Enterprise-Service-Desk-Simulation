ITSM-001 — Enterprise IT Service Desk Simulation

Project Overview

This repository documents a practical, hands-on Enterprise IT Service Desk simulation designed to demonstrate Level 1 (L1) IT support skills, incident management, troubleshooting, documentation, and escalation procedures.

The project simulates realistic workplace IT support scenarios using fictional employees, devices, and organisations.

It demonstrates the practical skills expected of a Junior IT Support Technician, Help Desk Technician, or Service Desk Analyst.

Project Objectives

- Demonstrate structured L1 troubleshooting.
- Practise incident identification, prioritisation, and resolution.
- Simulate Active Directory account administration.
- Investigate Windows operating system issues.
- Troubleshoot Microsoft 365 and common workplace applications.
- Document incidents and troubleshooting steps.
- Apply appropriate escalation procedures.
- Develop knowledge-base articles and technical reports.

Project Disclaimer

This is an independent learning and portfolio project. All users, organisations, devices, incidents, and supporting evidence are fictional or simulated.

No real company systems, customer accounts, or confidential information are represented.

The project is intended to demonstrate practical IT support knowledge and continuous professional development. It does not represent formal employment experience in an enterprise service desk environment.

Career Development

This project forms part of an ongoing professional development portfolio, supporting a career transition into IT Support and ultimately Cybersecurity / Security Operations.
